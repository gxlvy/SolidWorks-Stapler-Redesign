# SolidWorks Stapler Re-Engineering Project

A redesign of a conventional desktop stapler focused on improving accessibility,
functionality, material efficiency, and usability through iterative CAD design.

## Project Overview

This project involved modifying an existing stapler design in SolidWorks to address
several usability and design limitations. Three major modifications were developed:
a tactile orientation feature, an integrated staple storage system, and a redesigned
base intended to reduce material usage while maintaining stability.

## Design Modifications

### 1. Tactile Orientation Feature
- Added a textured surface to the front of the stapler.
- Provides a tactile reference for identifying the front and orientation of the device.
- Designed with accessibility for visually impaired users in mind.

### 2. Integrated Staple Storage
- Designed an internal compartment for storing additional staples.
- Added a sliding bolt/dispenser mechanism and hinged access door.
- Integrated the mechanism into the existing base while maintaining a compact design.

### 3. Redesigned Base Support
- Replaced the original large rubber base pad with smaller individual rubber feet.
- Positioned rubber components at key contact points to maintain grip and stability.
- Reduced the amount of rubber required in an attempt to lower material usage and cost.
- Retained compatibility with the existing base and mounting geometry.

## Engineering Design Process

The project followed an iterative redesign process:

1. Analyze the existing stapler geometry and functionality.
2. Identify opportunities for improved accessibility and functionality.
3. Develop modifications using SolidWorks.
4. Evaluate component fit and interaction within the existing assembly.
5. Refine the designs based on usability, material usage, and manufacturability.
